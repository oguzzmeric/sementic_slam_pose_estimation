│       │                                                                     │
│       ├── frame < 150 (WARMUP)                                             │
│       │       ├── GT displacement = t_GT_curr - t_GT_prev                  │
│       │       ├── s = ||GT_disp|| / ||t_unit_xy||                          │
│       │       ├── Moving median (window=20)                                 │
│       │       └──→ t_scaled = s * t_unit                                   │
│       │                                                                     │
│       └── frame ≥ 150 (AUTONOMOUS)                                         │
│               ├── YOLO bbox → h_pixel                                      │
│               ├── Z = (f_y * H_real) / h_pixel                            │
│               ├── scale = Z * |t_z| / ||t||                                │
│               ├── Başarısız → warmup median fallback                        │
│               └──→ t_scaled = s * t_unit                                   │
